# Honk 品牌素材

Logo 是字母 H 加一个未读角标（橙色 `#ff5a36`），底色 `#1c1c1e`。全部由 `scripts/brand/render.swift` 生成，不要手改。

| 文件 | 用途 |
| --- | --- |
| `honk-icon.svg` | 圆角图标（网页、文档） |
| `honk-icon-square.svg` | 方形全出血图标（系统自己加圆角的地方） |
| `honk-wordmark.svg` | 图标 + "Honk" 字标 |
| `honk-icon-{1024,512,256,128}.png` | 圆角图标位图 |
| `android/ic_launcher_foreground.png` | Android 自适应图标前景（432 px，内容在 66 dp 安全区内），背景色用 `#1c1c1e` |

iOS 的 App 图标在 `ios/App/Assets.xcassets/AppIcon.appiconset`（1024 方形，系统加圆角）。
